# HakGame

Source code of the official HakGame website: https://hakgame.com.tr

## What's inside

- **Apps:** English Learn and HakCode
- **Contact:** support@hakgame.com.tr

- CSS3 (custom properties, Grid/Flexbox, animations)
- Font Awesome icons, Inter font
